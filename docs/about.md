# About

This site is a companion to my [engineering and infrastructure portfolio](https://alvvvli.github.io/alvin-site/). It documents the journeys, sports, food, performances and everyday discoveries that sit alongside my technical interests.

The two sites share Material for MkDocs, IBM Plex typography, a slate appearance and the same navigation conventions. This site uses a forest-green identity.

The public archive intentionally omits personal travel identifiers, accommodation addresses, private correspondence and payment information.
