# Travels

A geographical index of documented journeys, alongside a separate set of previously recorded personal travels. Countries and places are organised by region; the travel log is not a count of countries visited.

**Reading the record:** A documented journey is not necessarily evidence that every attraction in its planning notes was visited. Confirmed travel, itinerary ideas, and cancelled bookings are kept separate. Flight connections alone do not establish entry into a country.
